# 时间关系图与真实证据

2026-10-22。`capture-to-policy.svg`为本项目原创结构图，按Apache-2.0许可提供；箭头长度不表示实测时长。相机/控制/写入/训练/异步预测/发送关系依据本地保存的LeRobot 0.6.1及项目v7源码。

三个交互图由`../timing-real.json`中真实事件生成，不是模型隐藏激活或机械臂仿真。逐帧泳道只画随图像保存的控制片段；全60Hz采集周期、真实曝光和电机生效时刻不可还原。推理图画输入锚点到主线程结果登记的包络；计算总耗时独立记录，不反推GPU起止。60Hz虚线仅是理想参考尺。

数据来源为Windows现有formal/episodes的50份alignment及50份summary、参考run control.jsonl和summary，以及三份源码；105个文件读取前后哈希一致，见`../../验证/时间证据源哈希.json`。原始采集、模型与控制程序未修改。
