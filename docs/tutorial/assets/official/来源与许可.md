## 4. 与项目配置的边界

1. 截的是VLM文字主干32层中的前16层，不是砍SigLIP视觉编码器一半。
2. 图示状态入口是模型取出当前状态后的`[B,6]`；真实训练外部batch保留观察时间轴，形状为`[B,1,6]`。
3. 113为64视觉+48文字位置+1状态；文字padding不参与有效注意力。
4. Flow Matching使用代码约定`x_t=t*ε+(1-t)*A`，t从1向0积分。不要与反向定义的τ混用。
5. `[B,50,32]`是内部动作宽度；真实监督/物理输出只用6维。
6. SA路径在实际实现中也能读取合法前缀；“动作互相交流”和“读VLM条件”是教学角色，不能推断两个通道绝对隔离。
7. 本次仅创建文档与SVG，没有在Mac或Windows安装环境、连接硬件、加载模型或执行推理。
