## 参考机器和公开便携包的入口不同

本机原工程使用中文启动器和 `D:\so-101`；公开便携包从所在仓库解析路径，入口为：

```text
Install.cmd → DownloadAssets.cmd → OfflineCheck.cmd
→ ConfigureHardware.cmd → TestYellowNut.cmd
```

安装与下载准备软件、模型、数据；OfflineCheck验证标准数据与单次模型输出，显式拦截串口/总线/相机；ConfigureHardware导入复现者已校准、验证的设备配置；Test入口才进入需要现场操作员的真机流程。公开包安装脚本来自参考锁定版本，尚未在另一台全新Windows上从零完整实测。

以下是参考机现有入口示例，本教程不会自动运行它们：

```powershell
Set-Location D:\so-101
# 需要正式采集时，操作员在场再打开
.\开始黄色螺母正式采集50条.cmd
# 需要模型测试时打开，第一次Enter归位，第二次Enter推理
.\测试黄色螺母模型5000.cmd
```

## 下一轮怎样获得有用结论

在当前固定起点与固定场景先进行约20次独立抓放，逐次重摆，记录起始位置/朝向、是否抓住、是否掉落、是否完整入盘、时间和失败阶段。把“能预测有限动作”“受限执行器正常”“这一次任务完成”“统计成功率”作为四层证据分别记录。

若主要失败在接近和闭合，应优先扩充起始位置、朝向、轻微滑动后的纠正示范；若集中在搬运保持，查看夹持、接触和发送目标；若集中在释放，先查队列是否到末尾及相位日志。改善后新建训练轮次，保留原50条和原5000步模型，不覆盖基线。任何摩擦材料或夹指结构变化也会改变视觉与接触条件，应记录并重新评估。


## 从单次改动学会做可比较实验

每一轮只明确改变一个主要因素，并记录相同的任务判定。比如保持模型/起点/相机不变，扩展螺母朝向；若失败增多，先检查这种朝向在50条示范中出现多少，再决定补采。若同时换模型、机位、夹指材料和限速，即使结果变好，也很难解释哪一个变化产生效果。这个习惯适用于数据工程、模型训练和机器人系统岗位。
