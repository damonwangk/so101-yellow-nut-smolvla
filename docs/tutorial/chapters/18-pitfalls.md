# 18｜一路遇到的问题与最终解决方案

[教程目录](../README.md) · [上一章](17-homing.md) · [下一章](19-reproduce.md)

> **学习目标：按层定位问题**
>
> 能在数据、模型、时序、接触条件之间提出可验证假设。

以下按层定位问题，记录有效原因和最终方案，省略错误堆栈、重复下载和中间重试。

| 现象 | 已确认原因 / 适用解释 | 最终方案 |
|---|---|---|
| 跟随关节偏差或编码跳变 | 主从编码参考不一致，部分路径接近编码接缝 | 调整连续编码参考，集中映射与版本绑定；训练动作统一从臂坐标 |
| 下摆起姿被启动检查拦住 | 人工摆位小幅超出正常工作范围 | 有界接入余量，首目标保持反馈，3秒回到原范围；不删除常态工作边界 |
| Q后从臂突然失去保持 | 录制结束等同整个控制进程退出 | 连续模式分离录制和控制，Q只保存，主臂复位不录制 |
| 重新启动/28条后续采报错 | 需要辨认已提交状态与残留力矩 | 按提交数续接；有限重试；现场R确认后释放核验 |
| 看不到刚录制文件 | 保存收尾被多次中断；逐条视图尚未生成 | 等SAVED，标准保存/finalize与提交状态一致后展示 |
| MP4无访问权限 | Windows输出文件权限不便于当前播放用户读取 | 继承目标目录读取权限，编码关闭后再查看 |
| loss看不到实时更新 | 后台进程与VS Code文本查看分开 | 训练循环直接flush打印，ConsoleTee与JSONL双保存 |
| loss降低但真机不抓 | 离线损失无法覆盖接触、对位和执行器时序 | 分开检查预测、实际发送、反馈、画面，先修复确定的执行问题 |
| 动作持续重做开头 | 用推理返回时间或队列弹出数代替实际受限进度 | 请求携带progress，身体限速共同缩放策略时间 |
| 抓后不动 | 受阻夹爪到位条件可能阻塞整臂 | 进度只由身体决定，夹爪仅范围限制 |
| 到盘前提前开 / 松爪尾部没执行 | 身体与夹爪相位错开；15帧覆盖截断后半段 | 同一接受相位采样，完整当前剩余段，保留最终关键帧 |
| 启动姿态各不相同 | 相机随腕部移动，状态/画面起点变化 | 训练起始medoid、受限归位、第二次Enter和新帧门控 |
| 触碰螺母就滑走 | 接触几何、桌面摩擦和物体姿态影响抓取 | 固定条件减少变化；后续补采真实变化与纠正示范 |
| 相同闭合目标有时夹不牢 | 位置控制不直接测力，角度/接触点改变有效夹持 | 保留持续闭合意图；不虚构力反馈；后续独立评估夹指接触与朝向覆盖 |

螺母滑动和夹持接触问题没有被纯软件彻底消除；参考位置成功不证明任意位置都能成功。固定起点、当前夹爪设置和队列修复解决的是已确认的变量及控制错误。后续应记录失败发生在接近、闭合、提起、搬运还是释放阶段，再决定是补采、改善夹指摩擦，还是修改控制。

---

**停一下，用自己的话回答：** 没有夹起螺母，能否直接归因于训练步数不够？

<details>
<summary>参考答案</summary>

不能。先对齐图像、预测、发送和反馈，确认队列/坐标/夹爪时序，再评估接触与覆盖。不同原因需要不同处理。

</details>
