# 黄色螺母模型实机测试

模型固定为本轮第5000步检查点，任务指令为夹取一个黄色螺母并放入棕色盘。正式数据和所有训练检查点保留，测试日志独立保存。

## 打开与操作

Windows窗口标题：`SO101 Yellow Nut - Model 5000 TEST`。也可双击桌面“黄色螺母模型5000测试”快捷方式，或`D:\so-101\测试黄色螺母模型5000.cmd`。

程序先加载模型及热身，之后接入原腕部相机和主从臂；显示READY后才接受开始键，加载期间误按的键会清除。第一次Enter前不启用电机力矩；归位及`AT_START`等待期间保持力矩。现有OpenCV为无图形界面版本，使用测试终端接收操作键；相机仍正常向模型提供实时图像，无需更换环境。

提示按顺序出现：加载完成后显示“请按一次 Enter 复位到固定起始位置”；复位期间显示“正在复位，请稍候……”；复位完成后才显示“请摆好黄色螺母并移开手，然后按第二次 Enter 开始推理”。

| 按键 | 行为 |
|---|---|
| 第一次Enter | 原3秒接入后，受原限幅保护移动到固定准备姿态；暂不执行模型动作 |
| AT_START后的第二次Enter | 先摆好螺母、移开手；收到确认后的新相机帧才开始模型测试 |
| Q | 暂停模型动作，保持当前位置及电机力矩 |
| R | 切换到主从跟随，用主臂复位；再次Enter仍先归位，到AT_START后再按Enter开始模型 |
| S | 人工标记本轮成功并保持当前位置 |
| F | 人工标记本轮失败并保持当前位置 |
| X / Ctrl+C | 退出并释放力矩；按之前先托稳从臂 |

每轮模型阶段最多运行45秒，不计归位和摆放等待时间；超时转保持状态。放盘完成时先观察，再按S；若需要中止，按Q保持。S/F是操作员标签，不是视觉自动判定成功。

固定准备姿态采用训练`episode_000022`第0帧，夹爪归一化开度约52.15；目标在`D:\so-101\configs\yellow-model-start-pose.json`，同帧参考图为`D:\so-101\configs\yellow-model-start-reference.jpg`。归位前留空运动路径，显示`AT_START`后再参照图摆放螺母。该回位不包含碰撞检测或避障，路径尚待实机验证。

## 已接入的控制保护

当前版本为`trajectory-phase-v7`，仍使用第5000步模型。

- 模型输出使用从臂坐标；R复位使用原主从映射，不重复叠加偏移。
- 身体五关节保留原工作边界、有限值与编码器连续性检查、3秒启动过渡及小幅摆位恢复；反馈超过35ms刷新，单次相对反馈5°，速度上限15°/秒。
- 夹爪按用户要求只保留原校准活动范围：不再受2个百分点相对限幅、15个百分点/秒限速、专用平滑/重叠渐变或启动渐变约束。身体策略时间由五个身体关节决定，夹爪未到空载闭合目标不会阻塞整臂。
- 按检查点`n_action_steps=50`完成当前预测剩余段至最后一帧后再换段，修复15帧重规划持续截掉后半段的问题；分数延迟对齐保留最终关键帧。身体保留7帧三角平滑和5帧换段过渡。推理仍在后台更新，换段采用新鲜预测；身体限速后夹爪取相同的已接受策略时间点，不添加夹爪专用限速或平滑。
- 结果超过1秒不接入；相机超过0.5秒、推理或新鲜观测超过1.5秒失联时保持；身体3秒不能推进一个策略帧也保持。
- Q、R或新轮次清空旧轨迹。启动前仍播种当前原始位置作为目标，退出时释放并回读力矩；底层驱动不另加相对目标限制。
- 归位由身体五关节实测误差不超过1°且稳定0.5秒判定到位；夹爪不参与该判定。准备阶段相机/推理进程失联、身体停滞3秒或准备超时进入HOLD。到位后须再次本地Enter，旧图像或旧轮预测不能启动策略。

38项回归、7893个真实限幅集成模拟周期、9种已有姿态共730周期归位模拟及300个夹爪受阻模拟周期通过。三段策略回放均能执行至最后一帧。验证期间硬件连接被显式拦截，调用次数为0。验证范围是控制约束和启动时序，不能代替回位路径或实机抓放效果验证。

## 本轮测试重点

当前先统一机械臂准备姿态和螺母摆放，观察接近时是否推走物体、能否稳定夹持和完整落盘。固定准备姿态不能自动判定抓住，也不提供自适应夹持力。当前使用位置目标；本轮未调整电机力矩/电流保护、未新增采集或训练。完整段执行修复及两次Enter流程已通过离线验证，当前没有启动机械臂。

模型每次推理请求的腕部JPEG副本保存在当前测试目录的`input_images`，对应状态和时间写入预测事件，便于定位抓取和释放误差。它们是诊断快照，不自动加入训练集。收尾示范统计与代表性尾帧位于`D:\so-101\logs\yellow-release-review`。
