## 1. 数据进入训练

源数据：`D:\so-101\datasets\yellow_nut_to_brown_tray\formal\lerobot`。

50条均通过技术检查且可确认放盘；13条轻微备注保留。首轮使用完整原数据，不执行尾段裁剪。训练读取单腕部图像、6维实测状态、英文任务指令，预测50步从臂绝对关节目标。

- 图像与未来动作窗口由官方LeRobotDataset读取；窗口在episode边界补齐，不跨入下一条。
- 相机/数据时间轴30FPS，控制目标60Hz；后续部署不能把动作以60Hz直接加倍播放。

## 2. 模型与更新

```text
已采集 LeRobot v3 数据
  → 按整条episode划分45/5
  → 计算训练集状态/动作归一化统计
  → 载入官方 smolvla_base 全部预训练权重
  → 本地tokenizer和预处理
  → 冻结VLM，训练动作专家、状态投影及动作相关投影
  → BF16前向/反向 → 梯度裁剪 → AdamW更新 → 余弦学习率
  → 每1000步验证5条保留示范并保存完整检查点
  → 保存验证损失最低的检查点路径
```

| 参数 | 本轮设置 |
|---|---|
| 首轮优化步数 | 20,000 |
| batch | 8，无梯度累积 |
| 精度 | CUDA BF16 autocast |
| 学习率 | 1e-4；1000步预热；余弦衰减至2.5e-6 |
| 图像 | 640×480源图，模型内部等比例填充至512×512 |
| 状态 / 动作 | 6维；50步动作窗口；从臂坐标，不再加主臂偏移 |
| 随机种子 | 1000 |
| 数据加载 | 0个子进程，PyAV，复用已验证的Windows加载方式 |
| 保存 | 首次100步；此后每1000步，实际保留至12000步 |
| 验证 | 每1000步，完整5条验证数据的flow matching损失 |
| 网络 | 使用本地权重与数据，不上传模型/数据 |

20,000步为原始首轮预算，实际在12,000步完成验证和保存后停止；batch按8GB配置调整，不能把本轮预算等同于官方示例batch64的训练量。验证损失最低为第5,000步的0.2090，第12,000步为0.2288。首次100步及每1000步至12000步共13个检查点全部保留。验证损失用于比较检查点，不代表机械臂真实抓放成功率。
